# monavia.com.br (pré-lançamento)

HTML estático do site da Monavia, servido pelo GitHub Pages enquanto o produto está hibernado (desde 24/11/2026).
**Não editar aqui.** É gerado a partir de `AgileSolutionOrg/monavia` (`apps/site`):

    STATIC_EXPORT=1 NEXT_PUBLIC_PRE_LANCAMENTO=1 npm run build   # copia `out/` para cá

No relançamento, o site volta para o servidor da Monavia; ver `docs/HIBERNACAO.md` no repositório principal.
